## About me

I'm an indie game developer. I build mobile games with **Unity** and **C#** and web applications with **ASP.NET Core MVC**, and I run my own studio, [Skylines Games](https://skylinesgames.com/). Lately I've been building AI-assisted development workflows with **Claude Code** and sharing them as open-source tools.

- **Mobile games:** Unity and C#, from the first prototype to the store release.
- **Web applications:** ASP.NET Core MVC and .NET.
- **Developer tools:** small, practical tools that take repetitive work off my plate, shared here on GitHub.
